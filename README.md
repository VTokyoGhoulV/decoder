# Decoder

Утилита для работы с кодировками текстовых файлов. Создаёт копию файла в UTF-8 для редактирования, а следующим запуском переводит её обратно в исходную кодировку.

**Стек:** Python, charset-normalizer, JSON.

## Как работает

Программа ищет первый `.txt` рядом со скриптом и определяет его кодировку через `charset-normalizer`. Если определить её не удалось, используется Windows-1251. `requirements.txt` в поиске не участвует.

Исходная кодировка сохраняется в `_original_encoding.json`. Наличие этого файла определяет режим следующего запуска.

## Установка

Команды для Windows PowerShell:

```powershell
git clone https://github.com/VTokyoGhoulV/decoder.git
cd decoder
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

## Использование

1. Сделайте копию исходного файла: обратное преобразование перезапишет оригинал.
2. Поместите один текстовый файл, например `notes.txt`, рядом с `decoder.py`.
3. Запустите программу:

   ```powershell
   .\.venv\Scripts\python.exe decoder.py
   ```

4. Отредактируйте созданный `notes_readable.txt` и сохраните его в UTF-8.
5. Выполните ту же команду ещё раз. Программа обновит `notes.txt` в сохранённой кодировке и удалит промежуточный файл вместе с `_original_encoding.json`.

Поиск выполняется в папке скрипта, независимо от папки терминала. Пользовательские `.txt` и файл состояния исключены из Git.

## Ограничения

- За один цикл обрабатывается один файл. Если `.txt` несколько, программа берёт первый найденный.
- Кодировка определяется предположительно и может быть выбрана неверно. Проверьте текст перед обратным преобразованием.
- Неподдерживаемые символы заменяются из-за `errors="replace"`. Переводы строк тоже могут измениться.
- Автоматического резервного копирования нет.
- Файл целиком загружается в память.
